# 🎧 Neon Music Player

A stylish music player UI built using HTML and CSS, featuring a dark aesthetic and neon purple-pink glow effects.

## ✨ Features

- Dark-themed music player interface
- Neon glow effects and gradients
- Album covers and song playlist
- Music control buttons
- Progress bar and volume slider
- Hover animations and transitions
- Responsive layout for smaller screens

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📸 Preview

Open `index4.html` in your browser to view the project.
